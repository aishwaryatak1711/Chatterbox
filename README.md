# ChatterBox++ 🤖

## Overview

**ChatterBox++** is a text-based AI chatbot built using **Object-Oriented Programming (OOP)** principles. It includes a **browser-based HTML/CSS/JavaScript frontend** and an **optional C++ backend server**. The chatbot uses the **Groq API** with the **Llama 3.3 70B** model to generate real-time AI responses.

---

## Features

* Real-time AI chat responses
* HTML/CSS/JavaScript frontend
* Optional C++ HTTP backend
* Groq API integration
* Demonstrates all four OOP pillars:

  * Encapsulation
  * Abstraction
  * Inheritance
  * Polymorphism

---

## Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** C++
* **API:** Groq API
* **AI Model:** Llama 3.3 70B

## How to Run

### Frontend

Open `index.html` in any modern web browser.

### Backend (Optional)

Compile and run:

```bash
g++ server.cpp chatbot.cpp -o chatterbox
./chatterbox
```
